# Masaka

Демонстрационный сайт суши-бара Masaka в Бишкеке.

`index.html` в корне — готовая HTML-версия для GitHub Pages. Исходники React, TypeScript и Tailwind находятся в папке `Masaka — весь проект`.

В настройках Pages выбран источник `main` → `/(root)`. Адрес после успешной публикации: https://aichurekmilashka-wq.github.io/masaka/

Меню и цены демонстрационные. Корзина не отправляет заказы в ресторан.
