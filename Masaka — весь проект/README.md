# Masaka — сайт суши-бара

Отдельный React-проект для Masaka в Бишкеке. Компонент конвейера из задания находится в `components/ui/sushi-conveyor-menu.tsx`; отдельный русскоязычный пример — в `components/ui/demo.tsx`.

## Посмотреть и запустить

`preview.html` — HTML-предпросмотр этой версии, который открывается без Node.js. Для загрузки React, Tailwind и фотографий нужен интернет. Это инструмент просмотра; для публикации используется обычная сборка Vite.

Для разработки нужен Node.js 22.12 или новее:

```sh
npm install
npm run dev
```

Vite выведет локальный адрес. Проверки и сборка:

```sh
npm test
npm run build
npm run preview
```

Собранный сайт будет в `dist/`. Публикация и отправка заказов не настроены.

## Структура и shadcn

Уже настроены React 19, TypeScript, Tailwind CSS 4, Vite и структура shadcn с `components.json`. React 19 нужен в том числе для передачи `ref` как свойства в предоставленном компоненте.

- `components/ui/` — переиспользуемые интерфейсные компоненты; импорт `@/components/ui/...`.
- `styles/globals.css` — основной файл стилей, переменные темы и пять цветов `chart` для тарелок.
- `src/App.tsx` — страница Masaka, каталог, контакты и корзина.
- `lib/menu.ts` — пример меню, русские подписи, цены, телефон, адрес, ссылка на карту.
- `lib/cart.mjs` — расчёты корзины и проверка сохранённых данных.
- `lib/utils.ts` — стандартная функция `cn` для shadcn.

Псевдоним `@/` указывает на корень проекта и одинаково задан в TypeScript и Vite. Папка `components/ui` важна для единообразных импортов и для того, чтобы shadcn CLI добавлял компоненты в ожидаемое место. Создавать дополнительную `src/components/ui` не нужно.

Добавление других компонентов:

```sh
npx shadcn@latest add button
```

При переносе в другой Vite-проект, в котором ещё нет этих инструментов:

```sh
npm install react react-dom lucide-react clsx tailwind-merge
npm install -D typescript @types/react @types/react-dom @types/node vite @vitejs/plugin-react tailwindcss @tailwindcss/vite
npx shadcn@latest init
```

Также перенесите настройки `paths` из `tsconfig.json`, `resolve.alias` и Tailwind-плагин из `vite.config.ts`. Основной CSS подключается из `src/main.tsx`. В текущем проекте повторная инициализация не нужна.

## Что подключено

Конвейер поддерживает перетаскивание, наведение, паузу, клавиатуру, окно состава и добавление блюда. В меню работают фильтры категорий; корзина позволяет менять количество и сохраняет выбор в браузере. Список блюд можно скопировать, ресторану можно позвонить, точное расположение открывается по исходной ссылке Яндекс Карт.

В компоненте сохранена логика исходного примера. Добавлена повторная привязка ResizeObserver при смене широкого и мобильного расположения: в этих режимах React создаёт разные контейнеры ленты.

## Данные ресторана и ограничения

Название Masaka, адрес «Бишкек, ул. Тоголок Молдо, 22» и телефон +996 707 77 77 47 взяты со скриншота пользователя от 01.11.2026. Источник: [переданная карточка Яндекс Карт](https://yandex.ru/maps/-/CXfHRQ9A). Короткая ссылка инструментом чтения не открылась, поэтому данные прочитаны со скриншота. Полное расписание не предоставлено; часы не выдуманы. Рейтинг не используется.

Все блюда, составы, фотографии и суммы — демонстрационные, адаптированные из предоставленного примера, а не утверждённое меню Masaka. Валюта — сом. На странице и в корзине есть соответствующие пометки. Фотографии загружаются с предоставленного CDN; при ошибке отображается замена. Иллюстрация в контактах схематичная, точная карта доступна по ссылке. Текстовый логотип — временное оформление названия, исходный фирменный логотип не предоставлен.

Для запуска реальных заказов нужно заменить пример на утверждённое меню и подключить согласованный канал оформления. Корзина сейчас не отправляет данные в ресторан и не принимает оплату. Публикация не выполнялась.

Подробности выполненных проверок — в `VERIFICATION.md`.
